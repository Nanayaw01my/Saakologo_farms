# Saakologo Farms Website

A modern, responsive, and professional website for Saakologo Farms - a leading provider of quality livestock and crop farming solutions in Ghana.

## Features

### 📱 Responsive Design
- **Mobile-First Approach**: Optimized for all device sizes (mobile, tablet, desktop)
- **Flexible Grid Layouts**: CSS Grid and Flexbox for adaptive layouts
- **Touch-Friendly**: Proper spacing and interaction areas for mobile users

### 🎨 Professional Design
- **Color Scheme**: Professional green (#1b5e20, #388e3c) and white design
- **Modern UI**: Clean, minimalist interface with smooth animations

- **Animations**: Smooth transitions and scroll animations

## How to Use

1. **Open in Browser**: Simply open `index.html` in your web browser
2. **Deploy**: Upload all files to your web server
3. **Customize**: Update colors, text, and images as needed

## Customization Guide

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-green: #1b5e20;
    --light-green: #2e7d32;
    --accent-green: #388e3c;
    /* ... other colors ... */
}
```

### Images
Replace Unsplash image URLs with your own:
- Update image URLs in `index.html`
- Consider image optimization for better performance
